# PESH TV

Personal Android TV / Google TV app.

Download **PeshTV.apk** from [the latest release](https://github.com/Pesh99/Pesh-tv/releases/latest). Install it over an existing PESH TV installation to preserve app data. Android 8.0 or later is required.

## Updates

Version 0.50 and later check this repository for new versions. You can also open **VIP Menu > App updates**. Android may ask you to allow installation from PESH TV and confirm the update.

## Version 0.50

- Down from the bottom letter row goes to Space.
- Keyboard side buttons display fully.
- Slim left-edge menu with Top and Search icons; Right closes it.
- Load More keeps existing poster views and appends new rows.
- Rapid Up navigation keeps the logical grid column.
- Today, This Week, and Newly Added lists use the website's rankings.

The update feed is `update.json`. APK releases use the same application ID and signing certificate.
